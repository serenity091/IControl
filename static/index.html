Connection & button mapping help

Phones and laptop must share the same Wi-Fi. If the QR page won’t load, select the laptop’s Wi-Fi address above, disable a VPN if it blocks local access, and check that the router does not isolate wireless clients. Allow Python through Windows Firewall on your private network. Enable Wi-Fi access.cmd in the project adds a rule restricted to private networks and the local subnet.

The phone uses Xbox labels and layout: A is green, B is red, X is blue, and Y is yellow. LB/RB are shoulders, LT/RT are triggers, and −/+ are Back/Start. L3 and R3 click the sticks. Bind Home manually if Eden supports it. Motion, NFC and capture are not provided.

Virtual controllers appear when phones join and are removed when they disconnect. Existing physical Xbox controllers may affect XInput numbering; use Eden’s input tester to identify each phone. Edit layout on a phone to drag any control and change its size. Layouts are saved in that browser.
